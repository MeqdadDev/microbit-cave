These projects add external hardware to the micro:bit. Each page lists the parts you need,
a wiring table and any helper library you must copy onto the board first.

!!! tip "Edge connector breakout"
    Pins beyond `P0`, `P1` and `P2` (like `P13`, `P16`, `P19`, `P20`) are only reachable
    through an edge connector breakout board.
